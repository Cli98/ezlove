# 易挂念 · 订阅消息模板配置与操作手册

> 日期：2026-09-24 ｜ 适用：微信小程序后台「订阅消息」配置 + 前后端对接 + 验证
> 背景：小程序类目为「慈善信息服务」（该账号下唯一类目），公共模板库共 **127 个**可用模板，已通过官方接口全量拉取筛选。

---

## 一、整条链路只有 3 步（官方机制）

```
① 微信公众平台选模板 → 得到「模板ID」
② 小程序端弹授权弹窗（用户点「允许」）→ 获得下发权限
③ 后端调用微信接口 → 下发到用户微信「服务通知」
```

关键机制（可复用规则）：

| # | 规则 | 说明 |
|---|---|---|
| 1 | **字段可裁剪** | 选模板时可从该模板的全部字段里**挑子集**（不超过 5 个），不需要的字段（如"时间"类）可以不勾 |
| 2 | **字段编号=原始位置** | 勾选的字段在发送时，键名沿用**原始序号**。例：勾了第2、4个字段（都是事物），发送键名是 `thing2`、`thing4`（不会重排为 thing1/thing2） |
| 3 | **字段类型必须对得上** | `thing`=20字内文本；`number`=纯数字；`time`=日期时间格式；`phrase`=平台固定选项（不能自定义）。发送值格式不对会报错 47003 |
| 4 | **一次性订阅=一次授权发一条** | 用户点一次"允许"，后端可发 1 条。本项目已在「发送牵挂后 / 进入提醒页时」请求授权，勾选"总是保持以上选择"后不再弹窗 |
| 5 | 选用公共模板**无需审核** | 提交即刻生效（"生效中"状态），模板 ID 立即可用 |

### 后台操作步骤（可复用）

1. 登录 mp.weixin.qq.com → 功能 → 订阅消息
2. 点右上角绿色「选用」→ 公共模板库搜索模板名称（如"互助服务进度通知"）
3. 进入选用页，**只勾选指定字段**（取消其他勾选）→ 提交
4. 回到"我的模板"，复制新模板的**模板 ID**（一长串字符）
5. 模板 ID 交给开发方（本手册第三节第 3 步）

> 顺带：检查「选用」页面是否存在**长期订阅**分类。如该类目有长期订阅模板（一次授权长期可发），优先改用长期订阅（家属无需反复授权）。

## 四、验证方法（端到端）

### 本地验证（开发方）
1. 本地后端 `.env` 填好模板 ID，重启 backend 容器
2. 开发者工具（模拟器连本地）→ 发送一条牵挂 → 弹出订阅授权 → 点"允许"
3. 后端手动触发未读检测（或等 5 分钟调度）→ 微信"服务通知"收到卡片
4. 若收不到：`docker logs ezlove-backend-1` 查 `发送订阅消息失败` 日志（错误码对照：47003=字段格式错；43101=用户未订阅）

### 线上验证（发布后）
1. 管理员配好 4 个变量 → `ezlove-release deploy`
2. 体验版真机：登录 → 发送牵挂 → 授权 → 等通知
